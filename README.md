# 活动抽奖系统

这是 Web 版本的本地抽奖系统：界面是静态前端页面，运行时由 Electron 打包成 Windows `.exe`。系统不需要 Python 后端或 Web 服务器，Excel 文件读写由 Electron 本地壳完成。

## 功能

- 导入活动 Excel 文件。
- 读取 `抽奖名单 / 奖品信息 / 中奖信息`。
- 支持手动输入 7 位工号。
- 支持扫码枪 9 位编码，自动截取前 7 位。
- 九宫格快速滚动抽奖。
- 扫码或输入后自动开始滚动，按 `Enter` 或 `Space` 停止。
- 按奖品剩余库存加权随机抽奖。
- 中奖后扣减库存并立即保存 Excel。
- 无资格人员记录为 `无抽奖资格`。
- 已中过奖的工号不能重复抽奖。
- 可导出中奖信息和 Excel 模板。

## 安装运行

```powershell
npm install
npm start
```

## 打包 exe

```powershell
npm run dist
```

打包产物会生成在 `dist/` 目录。系统数据保存在浏览器本地存储中，可以在管理员页面导入抽奖名单、配置奖品并导出中奖信息。

## Excel 文件要求

Excel 需要包含以下工作表：

- `抽奖名单`：必须包含 `工号` 列，系统只读取 7 位工号。
- `奖品信息`：必须包含 `奖品名称` 或 `奖品` 列，以及 `数量` 列；`图片` 列可选。
- `中奖信息`：前三列必须是 `工号 | 奖品 | 时间`。

每次中奖或无资格扫码记录都会立即保存到当前 Excel 文件。

## 现场操作

- 打开程序后输入框会自动聚焦。
- 手动输入 7 位工号后按 `Enter` 开始滚动。
- 扫码枪输入 9 位编码后会自动开始滚动。
- 九宫格滚动中按 `Enter` 或 `Space` 停止抽奖。
- 完成一次抽奖或提示后，输入框会自动清空并重新聚焦。
