# 活动抽奖系统

这是一个纯前端静态抽奖系统，运行时可由 Electron 打包成 Windows `.exe`。系统没有后端、preload 或 IPC，数据保存在浏览器 `localStorage` 中，Excel 导入导出在前端完成。

## 功能

- 管理员密码进入后台。
- 导入抽奖名单，名单包含 `姓名` 和 `工号`。
- 配置奖品名称、数量和奖品图片。
- 前台大屏左右布局展示活动信息、统计信息和奖品信息。
- 点击 `一键抽奖` 后先播放动画，再一次性生成并展示全部中奖结果。
- 中奖结果展示 `姓名 / 工号 / 奖品`，中奖人数较多时支持结果区滚动展示。
- 导出中奖信息，导出列为 `姓名 / 工号 / 奖品 / 时间`。
- 支持重置数据、刷新数据、保存活动标题。

## 安装运行

```powershell
npm install
npm start
```

也可以直接打开 `app/index.html` 预览静态前端页面。

## 打包 exe

```powershell
npm run dist
```

打包产物会生成在 `dist/` 目录。

## Excel 名单要求

导入文件需要包含工作表 `抽奖名单`，或使用第一个工作表。表头必须包含：

- `姓名`
- `工号`

系统会读取 7 位数字工号，过滤无姓名或无有效工号的行，并按工号去重。
